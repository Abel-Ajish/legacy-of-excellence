# Plan: Remove ngrok Browser Warning

## Problem
Free ngrok tunnels show an interstitial warning page to all visitors. To bypass it, responses must include the `ngrok-skip-browser-warning` header.

## Solution
Add custom response headers in `next.config.ts` that set `ngrok-skip-browser-warning: true` on all responses. This works in dev mode.

### File to modify
- `next.config.ts` — add `headers()` config returning the skip header for all paths

### Change
```ts
import type { NextConfig } from "next";

const nextConfig: NextConfig = {
  allowedDevOrigins: ['falsify-handwork-handbag.ngrok-free.dev'],
  async headers() {
    return [
      {
        source: '/(.*)',
        headers: [
          { key: 'ngrok-skip-browser-warning', value: 'true' },
        ],
      },
    ];
  },
};

export default nextConfig;
```

### Notes
- This only removes the warning for visitors accessing via ngrok
- The header must be set on responses, not requests
- Free ngrok accounts may still show the page intermittently — a paid plan removes it entirely

## Verification
1. Restart dev server (`npm run dev`)
2. Visit the ngrok URL — warning page should no longer appear
3. Visit localhost:3000 directly — should work as before
